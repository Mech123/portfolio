Ensemble

The ensemble combines predictions from multiple models to improve robustness and reduce error, especially around difficult regions like peak demand. Instead of relying on a single hypothesis about the data-generating process, an ensemble leverages complementary strengths of different models (e.g., classical seasonal structure from SARIMA and nonlinear dynamics from LSTM/Hybrid).

How this ensemble works (summary)

  • Inputs: base model predictions aligned on the same timestamps (e.g., SARIMA, LSTM, Hybrid).
  • Combination: a weighted (or constrained) combination such as linear weights or NNLS weights that minimizes validation error.
  • Goal: improve general accuracy and stabilize performance during peaks and rapid ramps.
  • Evaluation: compare against each base model using MAE/RMSE/MAPE, and optionally peak-specific metrics.
