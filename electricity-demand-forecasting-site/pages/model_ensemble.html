Ensemble

Back to Models

The Ensemble approach combines forecasts from multiple models (e.g., SARIMA, LSTM, Hybrid) to improve robustness and reduce variance. This is especially useful when individual models behave differently under peak-load conditions.

What this page contains

  • High-level explanation of the ensemble strategy used in this project
  • Links to outputs: metrics JSON and predictions CSV (stored under assets/data/ensemble/)
  • (Later) plots/figures can be added under assets/images/models/ensemble/
