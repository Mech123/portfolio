Conclusion

This project compares SARIMA, LSTM, hybrid SARIMA+LSTM, and ensemble methods for short-term electricity demand forecasting in Germany, with a special focus on peak-load stability and interpretability.

Key Takeaways (Expected)

  • SARIMA is a strong interpretable baseline with low compute cost.
  • LSTM learns nonlinear effects but needs explainability for operational trust.
  • Hybrid SARIMA+LSTM can improve peak accuracy by modeling nonlinear residuals.
  • Ensembles can reduce error variance and improve stability during peaks.
  • SHAP/LIME helps validate which features drive predictions (peak vs normal hours).

Next Steps

  • Add prediction intervals / uncertainty estimation
  • Run robustness checks across seasons and special days
  • Publish a small dashboard for operational interpretation
