Hybrid (SARIMA + LSTM residual)

Hybrid model where SARIMA provides a baseline forecast and an LSTM learns residual errors.

SARIMA LSTM Hybrid Ensemble
Open metrics JSON Open predictions CSV Notebook (GitHub)

Hybrid SARIMA+LSTM is implemented as a two-stage residual-correction model for hourly electricity demand forecasting (Germany, 2015–2018). First, a univariate SARIMA(1,1,1)(1,1,1,24) model forecasts the target_load series using a strict time split (train: 2015–2017, test: 2018). Residuals (actual − SARIMA forecast) are then learned by a stacked LSTM using 24-hour sliding windows over the multivariate input features (scaled with RobustScaler) and residual target (scaled separately). The LSTM uses two recurrent layers (64 and 32 units) with dropout and dense layers, trained with Adam and stabilized using early stopping and learning-rate reduction. Final hybrid predictions are created by adding the predicted residuals back to the SARIMA baseline, and performance is evaluated with overall error metrics plus peak-load focused analysis using a 90th-percentile threshold.
