Related Work

Short-term load forecasting (STLF) is a core task for grid operations. This project compares classical statistical methods and deep learning methods, and studies peak-load stability and explainability.

Statistical Forecasting

  • SARIMA is widely used for seasonal time series forecasting.
  • It is interpretable and reliable for stable patterns.
  • It can struggle during abrupt spikes and regime changes.

Deep Learning Forecasting

  • LSTM learns nonlinear patterns from history and exogenous drivers.
  • It can improve accuracy in complex conditions.
  • Explainability is important for operational trust.

Hybrid and Ensemble Approaches

  • Hybrid SARIMA+LSTM uses SARIMA to model structure and LSTM to learn residual errors.
  • Ensembles combine forecasts to reduce error variance and improve robustness.

Explainability

  • SHAP and LIME provide feature contribution explanations for model outputs.
  • This supports debugging and trust in high-stakes decision settings.
