Dataset

We use Open Power System Data (OPSD) time series data and focus on Germany for short-horizon electricity demand forecasting.

Source

  • Dataset: OPSD – Time Series (Version 2020-10-06)
  • Coverage: multiple European countries (Germany only used in this project)
  • Resolution: hourly (with some variants possible)
  • Format: CSV (and processed outputs can be stored as Parquet)

Variables

  • Electricity demand (load)
  • Generation from renewable and conventional sources (optional, depending on availability)
  • Weather variables (temperature and related drivers, when merged)
  • Calendar features derived from timestamp (hour, weekday, weekend, season, holidays if used)

Forecast Task

  • Horizon: 30 minutes to 1 hour ahead
  • Special focus: performance during peak-load periods
