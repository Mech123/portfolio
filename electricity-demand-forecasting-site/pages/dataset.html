Electricity Demand Forecasting (Germany)

Dataset

We use the Open Power System Data (OPSD) Time Series dataset (Germany) as the primary source for electricity demand. Weather variables are aligned to the same hourly timestamps.

Dataset Source

  • OPSD Time Series dataset page: Open dataset source
  • DOI (Version 2020-10-06): https://doi.org/10.25832/time_series/2020-10-06

What we use

  • Country: Germany
  • Resolution: 60 minutes
  • Target: Electricity load (MW)
  • Additional inputs: Calendar features + weather variables (used for LSTM/Hybrid)
