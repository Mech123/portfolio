Pre Processing

We build a consistent time-series dataset for forecasting and prevent leakage by preserving time order.

1) Time Handling

  • Ensure a continuous timestamp index
  • Handle missing timestamps and irregular intervals
  • Unify timezone representation (consistent UTC or chosen time base)

2) Cleaning & Imputation

  • Fill gaps in load/weather series (method depends on gap length)
  • Remove or flag extreme outliers (data issues vs true peaks)
  • Create a missingness report per feature and time period

3) Feature Engineering

  • Lagged load features (t−1, t−24, t−168)
  • Weather features (and optionally lags)
  • Calendar features (hour, weekday, weekend, season, holidays)

4) Normalization / Scaling

  • Scale numeric features for LSTM training
  • Keep SARIMA target consistent; invert transforms for evaluation

5) Merging & Splits

  • Join load + generation + weather into a unified table
  • Use time-based train/validation/test splits (no shuffling)
