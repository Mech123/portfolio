Electricity Demand Forecasting (Germany)

Pre Processing

This page summarizes the full preprocessing pipeline used to prepare Germany electricity demand and weather features for short-term load forecasting (SARIMA, LSTM, Hybrid, Ensemble). The steps below are taken from the project preprocessing notebook.

Links

  • Dataset (OPSD Time Series, 2020-10-06): Open dataset source • DOI
  • Preprocessing notebook (GitHub): Open preprocessing.ipynb

Processed Dataset Summary (60min)

  • Country: Germany
  • Resolution: 60 minutes
  • Rows: 32,665
  • Columns: 96
  • Time range (UTC): 2015-01-08 00:00:00 → 2018-09-30 00:00:00
  • Missing values after preprocessing: 0

Pipeline Summary

  1. Load data: import OPSD time series and merge with weather variables.
  2. Clean timestamps: enforce hourly resolution and correct ordering.
  3. Handle missing values: fill gaps and ensure complete continuous time index.
  4. Calendar features: hour/day/week/month, weekend indicators, holiday flags.
  5. Weather feature preparation: align weather to timestamps and standardize where needed.
  6. Finalize dataset: export processed 60-min dataset used by all models.
