Pre Processing

This preprocessing pipeline prepares OPSD electricity demand and weather data for time-series forecasting models.

Steps Performed

  • Loaded OPSD time-series data at hourly resolution.
  • Merged population-weighted weather data for Germany.
  • Reindexed timestamps to ensure continuous time series.
  • Detected outliers using IQR and Z-score methods.
  • Handled missing values using interpolation and forward/back filling.
  • Generated calendar-based and lagged features.
  • Normalized numerical features for model stability.
  • Exported cleaned datasets for modeling.
